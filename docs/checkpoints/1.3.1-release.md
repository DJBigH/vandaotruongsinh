# Vạn Đạo Trường Sinh 1.3.1

## Bản vá tải game và tương tác thú cưỡi

- Chia tải asset thành bộ dùng chung khi mở game và bộ hình riêng của bản đồ sắp vào. Với Kiếm Tu nam tu tiên, số tệp tải đầu giảm từ 442 xuống 196. Hình boss, NPC, cảnh và thú của bản đồ được tải xong trước khi vẽ cảnh. Có tiến độ và nút thử lại nếu tải lỗi.
- Lỗi gọi API nhân vật, hành trang hoặc nhiệm vụ hiện thông báo thử lại. Chỉ chuyển sang tạo nhân vật khi API xác nhận thật sự chưa có nhân vật.
- Health check chỉ trả trạng thái sẵn sàng khi PostgreSQL trả lời. Launcher nhận diện rõ tình trạng backend đang chạy nhưng DB lỗi.
- Bảng thú cưỡi dẫn tới bản đồ hoặc đóng bảng để người chơi tới hang thú; thu phục chỉ thực hiện bằng phím E cạnh thú trong thế giới.
- Sửa bài kiểm tra thưởng khi đổi nhân vật để tính đúng thưởng sự kiện theo khung giờ.
- Không thay đổi tỉ lệ cường hóa/thu phục, dữ liệu save, hình ảnh hay luật chơi 1.3.0.

## Kiểm tra

Đã chạy `npm run test:v131`, `npm run test:v130`, `npm run test:v130:routes`, `npm run test:v120`, `npm run test:v102`, `npm run test:all`, `npm run test:launcher`, build client/server/launcher. Đã kiểm tra PNG trả HTTP 200 trong bản build và chơi thử trên PostgreSQL riêng: tạo nhân vật, vào làng, vào rừng với 11 quái, đi qua cổng hai chiều, mở bảng thú và bản đồ. PostgreSQL thử nghiệm đã dừng sau kiểm tra.
