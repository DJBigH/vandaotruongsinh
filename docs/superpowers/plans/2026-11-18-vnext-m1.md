# VNext M0–M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish a verified baseline and deliver a playable, original-art Thanh Khê–forest slice while preserving existing accounts, characters, progress and combat rules.

**Architecture:** Retain Phaser 3 / React 18 / Fastify 5 / Prisma / PostgreSQL. Share world collision geometry between authoritative simulation and client prediction. Make socket/map lifecycles explicit, retain atomic rewards, and import original art through the existing frame contract. Changes stay on an isolated work branch.

**Tech Stack:** TypeScript, Phaser 3, React 18, Vite 5, Fastify 5, Prisma 6, PostgreSQL 16, existing tsx tests, Playwright for real-browser verification.

**Spec:** `docs/specs/VNEXT_REQUEST.md` (new request); `DOCS_GAME_DESIGN_DOCUMENT_VAN_DAO.md` (GDD 2.0). New original-art requirements supersede older permission to reuse core art packs.

## Global Constraints

- Base: `version-1`, inspected checkout `e36a57bf83bded68d22a19818c5ca89cc2014cb1`; preserve that upstream M1 work. Work branch: `codex/vnext-m1`.
- Web top-down real-time ARPG; three cultivation paths and three independent slots remain supported.
- Server owns valid position, damage, costs, cooldowns, i-frames, loot and progress. Do not remove collision or relax authority to hide stutter.
- Do not change damage, cooldown, movement speed, dash distance or i-frame values merely to fit animation.
- No production database, destructive reset, engine migration, backend rewrite, forced monetization or new PvP/MMO scope.
- Source art, exported art, integrated behavior and verified behavior are distinct statuses. No invented FPS/video/gameplay claims.
- Runtime sprite contract is currently 64×64, rows up/left/down/right. Retain compatible keys or migrate all consumers deliberately. Earlier standalone 96×96 art spec was provisional.
- Desktop verification at 1366×768 and 1920×1080. Use an isolated PostgreSQL test database; preserve real user saves.
- GitHub connection is read-only (`push: false`); prepare reviewable local commits and deliverable patch/bundle unless write access becomes available. Do not try to override repository permissions.

## Review Focus

- A stale socket closing after a replacement must not detach the replacement or overwrite a newer map/position save.
- Portal restart, F5 and lost focus must not duplicate listeners, sockets, stale inputs, mobs or rewards.
- Movement/dash must stop at walls, slide along their edges and leave NPCs/portals reachable.
- A player who walks to a chest must receive exactly one persistent reward through the real route, even under concurrent requests.
- Source sheets must stay inside their frame bounds, preserve readable body/face and animation timing, and match actual world geometry.
