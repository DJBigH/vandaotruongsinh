# Vạn Đạo Trường Sinh 1.0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a playable eight-chapter release with three distinct cultivation paths, clear animation, traversable maps, companion disciples and persistent endings.

**Architecture:** Keep the React/Phaser client, Fastify authoritative simulation and Prisma save model. Add deterministic world/content validation first, then change progression and companion behavior, integrate original art through the manifest and verify gameplay.

**Tech Stack:** TypeScript, Phaser 3, React 18, Fastify 5, PostgreSQL/Prisma 6, Python Pillow asset export.

**Spec:** `docs/superpowers/specs/2026-11-20-v1.0.2-design.md`

## Global Constraints

- Preserve existing account, character, inventory, quest and ending data; use a disposable loopback `_test` database for write tests.
- Server owns movement, combat, rewards and companion attacks.
- ART_DIRECTION.md defines 64×64 hero cells, foot anchor (32,56), and up/left/down/right row order.
- Three paths must have equivalent story and reward access; no purchased power.
- Report measured gameplay and FPS honestly; no release claim from a passing build alone.

## Review Focus

- A newly created Pháp Tu/Thể Tu receives path-compatible skill and gear and can finish the chapter chain.
- Every map's entry and return portal is reachable by an actor with collision radius 10, including boundaries.
- A reconnect, double click or competing request cannot grant a second quest/ending/companion reward.
- A dead, switching or disconnected character cannot keep a companion attacking.
- Missing asset/animation frame fails validation rather than silently becoming a colored square.
